# WL Position Checker

Расширение для Chrome. Оно следит за позициями в кабинете [Whitelist](https://moex.whitelist.capital) и сообщает, когда они меняются: позиция появилась или закрылась, сменились направление и объём, результат или заявки.

Пока Telegram не подключён, сообщения приходят в браузер. После привязки их присылает бот.

## Установка

1. Скачайте архив последней версии со [страницы релизов](https://github.com/artloop/wl_pos_extension/releases/latest).
2. Распакуйте его в отдельную папку.
3. Откройте `chrome://extensions`, включите «Режим разработчика» и нажмите «Загрузить распакованное расширение».
4. Укажите эту папку.

## Как пользоваться

1. Войдите в кабинет Whitelist в том же Chrome.
2. Откройте расширение и нажмите «Разрешить доступ».
3. В окне видны текущие позиции. Значок шестерёнки выбирает, о каких событиях сообщать.
4. Если баннеры браузера выключены, число новых изменений копится на значке расширения. Открытие окна это число снимает.
5. Кнопка со стрелкой переносит оповещения в Telegram. Откроется чат с ботом: подтвердите привязку. После этого сообщения о позициях приходят в Telegram, а не в браузер.
6. Если для этого кабинета уже сохранены другие настройки оповещений, расширение спросит, перенести ли настройки этого браузера или оставить прежние.

Повторное нажатие на кнопку Telegram начинает привязку заново.
